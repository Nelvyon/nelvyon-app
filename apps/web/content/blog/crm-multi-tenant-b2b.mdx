Elegir un CRM no es comparar listas de funciones en una tabla de marketing. Es evaluar si el producto aguanta operación real: multi-tenant, permisos, integración con campañas y estados honestos cuando falta configuración.

## Aislamiento por tenant

En entornos B2B, cada organización debe ver solo sus datos. Pregunte cómo se implementa el scoping en API y base de datos — no basta con “tenemos multi-tenant” en la landing.

## RBAC que el equipo usa

Roles y permisos deben reflejarse en pantalla. Si marketing no puede disparar acciones de billing, el producto debe impedirlo en backend, no solo ocultar botones.

## Contexto comercial completo

Un CRM aislado del pipeline, inbox y campañas obliga a saltar entre herramientas. NELVYON diseña la ficha de contacto arrastrando historial actionable de emails, etapas y automatizaciones.

## Honestidad operativa

Si el envío de email requiere AWS SES configurado, la UI debe decirlo. No simulamos entregas exitosas cuando la infraestructura no está lista.
