# Auditoría visual — Web pública NELVYON

> Fecha: 2026-08-01 · **Sin deploy** · Referencias: HubSpot · Stripe · GoHighLevel · OpenAI · Vercel · Linear  
> Criterio: calidad percibida de marca tecnológica propia (no plantilla Envato / no Sofax).

## Veredicto

La web sigue midiendo como **landing multipágina**, no como sitio corporativo de escala HubSpot/GHL. Blanco iniciado, pero profundidad, catálogo y media insuficientes.

| Referencia | Qué hacen bien | Gap NELVYON |
|---|---|---|
| Stripe | Blanco, aire, producto héroe, tipografía calmada | Glow azul residual; ritmo corto |
| HubSpot | Enciclopedia de producto/solución | Pocas URLs de módulo/servicio/sector |
| GoHighLevel | Feature catalog + captura por módulo | Un solo mock dashboard |
| OpenAI / Anthropic | Narrativa + motion sutil | Copy genérico en bloques |
| Vercel / Linear | Jerarquía quirúrgica, componentes propios | Icon-grids repetitivos tipo plantilla |

## P0 (obligatorio)

1. Escala de sitio (decenas de URLs producto/servicio/sector)
2. Profundidad: Home 25+ · detalle 12–16 secciones
3. Mocks multi-variante por módulo
4. Menos azul / más blanco y aire
5. Más fotografía + capturas
6. Narrativa: comparativas, timelines, tabs, mid-CTAs
7. Mega-nav alineada al catálogo
8. Agencia = páginas completas (no lista)
9. Sectores verticales reales
10. Integraciones enormes con iconos + status
11. Motion elegante (tabs, slider, hover, counters)
12. Status honesto (`en_producto` / `por_proyecto` / `enterprise`) — cero vaporware

## Decisión

- **No Sofax.** Referencia de calidad: Stripe (aire) + HubSpot/GHL (escala) + Linear (jerarquía).
- Marketing producto en `/producto/*`; app en `/saas/*`.
- **Sin deploy** hasta auto-aprobación de calidad percibida.
