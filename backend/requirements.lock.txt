# COMO SE GENERO
# --------------
# En un entorno virtual VACIO, para que no se colara nada del sistema:
#
#     python -m venv /tmp/venvlock
#     /tmp/venvlock/bin/pip install -r requirements.txt
#     /tmp/venvlock/bin/pip freeze --all --exclude-editable
#
# `pip` / `setuptools` / `wheel` quedan fuera: los aporta el entorno, no el
# proyecto.
#
# COMO SE USA
# -----------
#     pip install -r requirements.lock.txt      # reproducir exactamente
#     pip install -r requirements.txt           # resolver de nuevo (al actualizar)
#
# `requirements.txt` sigue siendo la fuente de intencion. Este fichero se
